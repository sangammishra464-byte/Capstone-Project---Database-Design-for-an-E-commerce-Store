# Capstone-Project---Database-Design-for-an-E-commerce-Store
Designed and implemented a complete database system for an e-commerce store, including tables for customers, products, orders, payments, and inventory management. Applied SQL concepts like normalization, joins, constraints, and queries to ensure efficient data storage, smooth transactions, and accurate business reporting.

This project focuses on designing and implementing a structured relational database for an e-commerce store using SQL. The database is built to efficiently manage customers, products, orders, payments, inventory, and shipping details while maintaining data accuracy and scalability.

The main objective of this project is to demonstrate practical database design concepts such as entity relationships, normalization, primary and foreign keys, indexing, and query optimization. The system supports real-world e-commerce operations including product management, customer transactions, order tracking, and sales analysis.

Project Objective

The goal of this capstone project is to create a scalable and efficient database system capable of handling day-to-day operations of an online shopping platform while ensuring data consistency, security, and efficient query performance.
